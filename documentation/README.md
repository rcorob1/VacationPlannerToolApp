# WGU D424 - Vacation Planner Tool 
## User Guide for Development Setup
To begin setting up a development environment for maintenance of this project, install Android Studio. Next, open GitLab to the Vacation Planner Tool repository, and move to the "dev" branch. Press the "Code" dropdown button, and copy the link to Clone with HTTPS. In Android Studio, from the top toolbar click Git->GitLab->Clone Repository. Then select Repository URL on the left side, and paste the URL into the URL Text Box. This will import the Vacation Planner Tool project into Android Studio for future development.

## User Guide to Install Application
To install the Vacation Planner Tool application, download the signed release.apk file found in the /release/ directory to your android device, and once on your Android device, use the Files app to select the APK file which will prompt you to install the application. Select Yes to install the application, and it will be installed to your device.
